## Background
A video game for the Norwich Science Festival 2023 by the Langridge Lab at the Quadram Institute. 

The aim is to design a diagnostic test for a make-believe infectious agent. 

There are three considerations to be made:
1. What kind of test is it going to be?
2. Who will be taking the test?
3. How sensitive is your test going to be?

The game can be run on a Raspberry Pi 3B+ or any laptop/PC. The game uses barcode scanners to interact.

## Install
Dependencies:
- Python >=3.8
- Pygame
- At least one barcode scanner

1. Either `git clone` or download the repository as a zip folder (will require being unzipped once downloaded).
2. Enter the QIB-NSF-2023 folder.
3. Double click `game.py` or run the command `python game.py`
